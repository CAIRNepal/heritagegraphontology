# Mapping rating (B2)

`mapping_rater_sheet.csv` (generated by `python3 scripts/gen_rater_sheet.py`) lists every mapping in
the published SSSOM set with both terms' labels and definitions.

1. **Rater 1** (not an author of the mapping) judges every row with `scope = core` (at least) and
   fills in `verdict`: `accept` (the predicate and target are right), `reject` (the target is
   wrong), or `revise` (right target, wrong strength; give `suggested_predicate`), plus `rater`
   (name or initials), `date` and, for reject/revise, a `note`.
2. **Rater 2**, independently and without seeing rater 1's sheet, judges the rows marked
   `second_rater = yes` (a fixed 30% sample of the core mappings).
3. Agreement: `python3 evaluation/rater_agreement.py rater1.csv rater2.csv` prints Cohen's kappa
   and the disagreements. The raters resolve them together.
4. Copy the resolved verdicts (columns `subject_id, predicate_id, object_id, verdict, rater, date,
   note`) to `evaluation/mapping_rater_verdicts.csv`, then run `python3 scripts/gen_sssom.py`
   (accepted mappings get the rater as SSSOM reviewer; rejected ones leave the set) and
   `python3 evaluation/mapping_audit.py`. Fix rejected or revised mappings in the YAML or the LUX
   module, regenerate, and report the counts and kappa in the paper.
