# Competency Questions → TBox-Only SPARQL ASK Queries

These ASK queries validate that the released ontology (`ontology/HeritageGraph.ttl`, v1.0.0) declares every class, property, and enumeration individual each competency question needs. They do **not** require instance data; the instance-level queries are `examples/queries/cq-abox-32.rq`, run by `evaluation/run_abox_cq32.py`.

Generated by `scripts/gen_cq_tbox_doc.py` from the instance-level queries; every ASK below returns `true` against the released TTL. Do not edit by hand.
