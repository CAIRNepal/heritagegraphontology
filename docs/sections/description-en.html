HeritageGraph–LUX alignment (Linked Art / CIDOC-CRM): Description back to ToC

Class- and property-level mapping from CAIR Nepal HeritageGraph to LUX, the Yale Linked Art / CIDOC-CRM dataset, validated against the official Linked Art JSON-LD context. A modular companion that imports the HeritageGraph core ontology and adds (a) formal owl:equivalentClass / owl:equivalentProperty axioms to CIDOC-CRM, (b) 33 interoperability classes rooted in the URIs LUX actually emits, and (c) the HG-internal hierarchy and object properties wiring those classes into the core graph.
