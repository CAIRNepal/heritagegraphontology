# Concept schemes

### Architectural Style (concept scheme)

**IRI:** `https://cair-nepal.org/heritagegraph/scheme/ArchitecturalStyle`

A vocabulary of architectural styles for South Asian heritage, mapped to CIDOC E55 Type.

### Condition Type (concept scheme)

**IRI:** `https://cair-nepal.org/heritagegraph/scheme/ConditionType`

Controlled vocabulary for the physical condition of heritage objects and structures.

### Date Precision (concept scheme)

**IRI:** `https://cair-nepal.org/heritagegraph/scheme/DatePrecision`

Controlled vocabulary for the temporal precision of recorded heritage dates.

### Existence Status (concept scheme)

**IRI:** `https://cair-nepal.org/heritagegraph/scheme/ExistenceStatus`

Controlled vocabulary for whether a heritage structure still exists physically.

### Guthi Type (concept scheme)

**IRI:** `https://cair-nepal.org/heritagegraph/scheme/GuthiType`

Controlled vocabulary of Guthi functional types (CRM E55_Type)

### HeritageGraph LinkML schema

**IRI:** `https://cair-nepal.org/heritagegraph/schema` · `heritageGraph:schema`

The LinkML schema from which this ontology is generated; every generated term is skos:inScheme it.

### Ritual Type (concept scheme)

**IRI:** `https://cair-nepal.org/heritagegraph/scheme/RitualType`

Controlled vocabulary of ritual and festival activity types in Kathmandu Valley living heritage.

### Syncretic Type (concept scheme)

**IRI:** `https://cair-nepal.org/heritagegraph/scheme/SyncreticType`

Controlled vocabulary for kinds of syncretic theological relationships between deities.
